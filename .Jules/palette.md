## 2026-10-25 - Explicit Form Labels & Screen Reader Announcements in Plain HTML Slot Game
**Learning:** Legacy standalone HTML files often lack proper `<label for="...">` associations for numeric inputs and `aria-live` regions for dynamic game results.
**Action:** Always wrap or associate inputs with `<label>` tags and add `aria-live="polite"` to status elements when enhancing vanilla HTML interfaces.
