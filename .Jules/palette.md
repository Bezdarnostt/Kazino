## Learnings
## 2026-10-19 - Form Accessibility & Focus States in Plain HTML Slot Machine
**Learning:** Plain HTML controls in legacy static files often lack associated form labels and `:focus-visible` indicators, making screen reader and keyboard navigation impossible. Dynamic output containers like game messages benefit immensely from `aria-live="polite"` for non-disruptive feedback.
**Action:** Always link labels with `for` attributes and ensure clear keyboard focus rings with `:focus-visible`.
