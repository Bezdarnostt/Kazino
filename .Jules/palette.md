## 2026-10-31 - Accessible Dynamic Status & Initial Slot Render in Standalone HTML Games
**Learning:** Standalone HTML slot machines with dynamic reel creation often display a blank void until explicitly started, leaving initial balance at 0 and confusing players. In addition, inputs without `<label for="...">` and dynamic result text lacking `role="status"`/`aria-live="polite"` make games inaccessible to screen reader and keyboard users. Initializing the game state upon `window.onload`, associating labels, and adding `:focus-visible` styles ensures immediate visual clarity and accessibility.
**Action:** Always ensure initial component state renders on load, form controls have matching label `for` attributes, and dynamic feedback containers use live regions with distinct keyboard focus styling.
